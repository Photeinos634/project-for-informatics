# B-multiple-repair-candidates

## 担当
B担当（Encoding Engine）

## 概要
同一バイト列を複数の文字コードでデコードし、修復候補を生成する。

## 実装要件
- 候補文字コードごとにデコードを実行する。
- 不正バイト列、置換文字多発、空出力を警告または除外する。
- 候補ごとのスコアと説明を返す。
- ISO-2022-JPはバイト列全体を一度だけデコードする。
- 重複する出力と文字コードを統合する。

## 公開API案
`suggestRepairCandidates(bytes, targetEncodings?)`

## 完了条件
- 候補は実際のデコード結果に基づく。
- スコアは相対的な推定である。
- ライブラリ固有例外を共通型へ変換する。
