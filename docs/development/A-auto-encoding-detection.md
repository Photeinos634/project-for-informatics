# A-auto-encoding-detection

## 担当
A担当（Frontend / UI）

## 概要
バイト列またはHEX入力に対する文字コード候補を表示し、候補選択をC担当へ渡すUIを定義する。

## 対象コンポーネント
- TextInput / HEXエディタ
- EncodingSelector
- 新規候補表示UI

## UI要件
- 候補を信頼度順に表示する。
- 候補ごとの判定根拠を表示する。
- 判定未実行、候補なし、低信頼を区別する。
- 候補選択は明示的なユーザー操作とする。
- 自動判定だけで文字コード選択を上書きしない。
- 処理中・失敗・結果なしを表示する。

## 使用するインターフェース
`EncodingDetectionResult` と `EncodingDetectionCandidate` をC担当から受け取る。

## 完了条件
- 複数候補を選択できる。
- 推定であることが利用者へ明示される。
- 判定失敗時に成功表示しない。
- モバイルでも候補を操作できる。
