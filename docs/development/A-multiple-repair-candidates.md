# A-multiple-repair-candidates

## 担当
A担当（Frontend / UI）

## 概要
文字化け修復候補を比較できる一覧UIを定義する。

## 表示要件
- 修復後テキスト、変換元、変換先、信頼度を表示する。
- 候補選択時に結果欄へ反映する。
- 候補なし・低信頼・生成失敗を区別する。
- 候補を正解として断定的に表示しない。

## 使用インターフェース
`RepairResponse` と `RepairCandidate`

## 完了条件
- 重複候補を統合する。
- 選択後にどの文字コードを使用したか確認できる。
- モバイル表示に対応する。
